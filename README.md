# Crop Yielding Prediction System

## Overview

Crop Yielding Prediction System is a Java Swing based desktop application developed using Java, Oracle Database, JDBC, and Eclipse IDE.
The project helps users:
* Predict expected crop growth
* Get fertilizer recommendations
* Find crops suitable for different soil types and rainfall conditions
* Manage crop records through admin mode

---

## Technologies Used

* Java
* Java Swing
* Oracle SQL
* JDBC
* Eclipse IDE

---

## Features

### Fertilizer Recommendation

Provides fertilizer and pesticide suggestions based on:

* crop type
* crop name
* soil type
* land area

### Expected Growth Prediction

Predicts crop yield using:

* rainfall
* soil type
* previous yield data
* cultivation area

### Crops by Soil & Rainfall

Displays suitable crops based on soil conditions.

### Admin Module

Allows admin to:

* add crop details
* delete crop details
* manage recommendations

---

## Software Requirements

* Java JDK
* Eclipse IDE
* Oracle Database
* Oracle JDBC Driver (ojdbc)

---

## How to Run

1. Open the project in Eclipse IDE
2. Add Oracle JDBC Driver to project libraries
3. Configure Oracle Database connection
4. Run the main file:
   CropYieldingSyst.java

---

## Database Note

This project uses Oracle Database with JDBC connectivity.

Database files are not included in this repository.

Main tables used:

* crop_recommendation
* crop_history
